# ⌨️ Shortcuts

> Never take your hands off the keyboard, and your thoughts never break. These are the default bindings — you can remap all of them in **Settings → Shortcuts**. 🛠️

## 🖥️ System

| Shortcut | Action |
| -------- | ------ |
| `Ctrl+O` | Quick open file |
| `Ctrl+P` | Command palette |
| `Ctrl+S` | Save |
| `Ctrl+,` | Open / close Settings |
| `Ctrl+W` | Close window |
| `Esc` | Dismiss hints |

## 🔄 Modes

| Shortcut | Action |
| -------- | ------ |
| `Ctrl+/` | Toggle between Live Render and Source mode |
| `Ctrl+Alt+T` | Typewriter mode |

## ✏️ Editing

| Shortcut | Action |
| -------- | ------ |
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |
| `Ctrl+F` | Find |
| `Ctrl+H` | Replace |
| `Ctrl+A` | Select all (inside code block) |

## 🎨 Formatting

| Shortcut | Action |
| -------- | ------ |
| `Ctrl+B` | Bold |
| `Ctrl+I` | Italic |
| `Ctrl+D` | Strikethrough |
| `Ctrl+E` | Inline code |
| `Ctrl+U` | Code block |
| `Ctrl+K` | Hyperlink |
| `Ctrl+=` | Highlight |
| `Ctrl+;` | Quote |
| `Ctrl+Shift+H` | Horizontal rule |

## 📑 Headings

| Shortcut | Action |
| -------- | ------ |
| `Ctrl+1` ~ `Ctrl+6` | Heading 1 ~ 6 |
| `Ctrl+0` | Paragraph |

## ✅ Lists

| Shortcut | Action |
| -------- | ------ |
| `Ctrl+L` | Bullet list |
| `Ctrl+J` | Task list |
| `Ctrl+Shift+J` | Toggle task state |
| `Ctrl+Shift+O` | Indent |
| `Ctrl+Shift+I` | Outdent |

## 📊 Insert & Tables

| Shortcut | Action |
| -------- | ------ |
| `Ctrl+T` | Insert table |
| `Ctrl+Shift+B` | Insert above |
| `Ctrl+Shift+E` | Insert below |
| `Ctrl+Shift+F` | Table: insert row above |
| `Ctrl+Shift+.` | Table: insert row below |
| `Ctrl+Shift+G` | Table: insert column left |
| `Ctrl+Shift+=` | Table: insert column right |
| `Ctrl+-` | Table: delete row |
| `Ctrl+Shift+-` | Table: delete column |
| `Ctrl+Shift+L` / `C` / `R` | Table: align left / center / right |

## 🪟 View

| Shortcut | Action |
| -------- | ------ |
| `Alt+1` | Toggle left sidebar |
| `Alt+2` | Toggle right sidebar |
| `Ctrl+M` | Mind map |
| `Ctrl+\` | Split horizontally |
| `Ctrl+-` | Split vertically |
| `Ctrl+\`` | New terminal |

---

Can't remember them all? No worries. Press `Ctrl+P` any time — every feature understands what you type. 💬
