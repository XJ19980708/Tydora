# ⌨️ 快捷键

> 手不用离开键盘，思路就不会断。以下为默认键位，均可在 **设置 → 快捷键** 中改成你顺手的样子。🛠️

## 🖥️ 系统

| 快捷键 | 功能 |
| ------ | ---- |
| `Ctrl+O` | 快速打开文件 |
| `Ctrl+P` | 命令面板 |
| `Ctrl+S` | 保存 |
| `Ctrl+,` | 打开 / 关闭设置 |
| `Ctrl+W` | 关闭窗口 |
| `Esc` | 关闭提示 |

## 🔄 模式

| 快捷键 | 功能 |
| ------ | ---- |
| `Ctrl+/` | 在即时渲染与源码模式间切换 |
| `Ctrl+Alt+T` | 打字机模式 |

## ✏️ 编辑

| 快捷键 | 功能 |
| ------ | ---- |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` | 重做 |
| `Ctrl+F` | 查找 |
| `Ctrl+H` | 替换 |
| `Ctrl+A` | 全选（代码块内） |

## 🎨 格式

| 快捷键 | 功能 |
| ------ | ---- |
| `Ctrl+B` | 加粗 |
| `Ctrl+I` | 斜体 |
| `Ctrl+D` | 删除线 |
| `Ctrl+E` | 行内代码 |
| `Ctrl+U` | 代码块 |
| `Ctrl+K` | 超链接 |
| `Ctrl+=` | 高亮 |
| `Ctrl+;` | 引用 |
| `Ctrl+Shift+H` | 水平分割线 |

## 📑 标题

| 快捷键 | 功能 |
| ------ | ---- |
| `Ctrl+1` ~ `Ctrl+6` | 一级 ~ 六级标题 |
| `Ctrl+0` | 段落 |

## ✅ 列表

| 快捷键 | 功能 |
| ------ | ---- |
| `Ctrl+L` | 无序列表 |
| `Ctrl+J` | 任务列表 |
| `Ctrl+Shift+J` | 切换任务状态 |
| `Ctrl+Shift+O` | 增加缩进 |
| `Ctrl+Shift+I` | 减少缩进 |

## 📊 插入与表格

| 快捷键 | 功能 |
| ------ | ---- |
| `Ctrl+T` | 插入表格 |
| `Ctrl+Shift+B` | 在上方插入 |
| `Ctrl+Shift+E` | 在下方插入 |
| `Ctrl+Shift+F` | 表格：上方插入行 |
| `Ctrl+Shift+.` | 表格：下方插入行 |
| `Ctrl+Shift+G` | 表格：左侧插入列 |
| `Ctrl+Shift+=` | 表格：右侧插入列 |
| `Ctrl+-` | 表格：删除行 |
| `Ctrl+Shift+-` | 表格：删除列 |
| `Ctrl+Shift+L` / `C` / `R` | 表格：左 / 中 / 右对齐 |

## 🪟 视图

| 快捷键 | 功能 |
| ------ | ---- |
| `Alt+1` | 切换左侧栏 |
| `Alt+2` | 切换右侧栏 |
| `Ctrl+M` | 思维导图 |
| `Ctrl+\` | 左右分屏 |
| `Ctrl+-` | 上下分屏 |
| `Ctrl+\`` | 新建终端 |
