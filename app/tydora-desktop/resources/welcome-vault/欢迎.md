# 👋 欢迎来到 Tydora

这里是一张白纸。📄

此刻，你正在读的这段文字，和你将来在这里写下的每一个字，都以最朴素的 Markdown 格式，安静地躺在你自己的电脑上。不上传，不锁定，十年后依然在。🔒

写作应该是一件简单的事：一个想法💡，一支笔✒️，一张不催促你的纸📄。Tydora 想做的就是这样一张纸。

## ✍️ 两种方式落笔

按 `Ctrl+/`，感受一下：

- **即时渲染模式** ✨ —— 你现在看到的样子。**加粗**、*斜体*、`代码`、==高亮==，随手可用，所见即所得。
- **源码模式** ⌨️ —— 同一篇文字的素颜。纯粹的 Markdown 字符，适合喜欢敲符号的人。

你可以在任何时刻切换，文字不会丢。

## 🌱 一些值得一试的事

- 🔗 用 `[[欢迎]]` 这样的双链，把想法连成一张网；再用关系图谱看看它们长成了什么形状。
- 🧠 按 `Ctrl+M`，让一篇笔记变成一张思维导图。
- 🧩 把卡片拖上白板，在无限画布上重新排列你的灵感。
- 🔍 按 `Ctrl+P` 呼出命令面板——忘记功能在哪里的时候，它总在那里。
- 💻 按 \`Ctrl+\`\` 打开终端，写作与命令行只隔一个反引号。
